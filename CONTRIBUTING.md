# Contributing to monitor-secure-pipeline

Thanks for your interest in contributing.

## Getting Started

1. Fork the repository and clone your fork.
2. Create a branch for your change: `git checkout -b fix-short-description`.
3. Make your change and add tests where it makes sense.

## Pull Requests

1. Keep each pull request focused on one change.
2. Describe what changed and why.
3. Make sure existing checks still pass before opening the pull request.

## Code Style

- Match the style of the surrounding code.
- Keep lines short and names clear.
- Do not commit secrets, credentials, or generated files.
